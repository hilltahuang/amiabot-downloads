amiabot 0.2.2 connects installed clients to the reviewed live content system.
Online game loads can receive city announcements, daily opportunities and
scheduled shop/recruitment rules, including bounded fictional prices and pay.
Device-only offline play continues using bundled content.

The sign-in screen checks the latest published app version after connecting to
cloud services and offers a link to the official download page when an update
is available. Updates are installed deliberately; no remote code is downloaded
or executed by the game. Navigation sprite effects have been simplified for
consistent rendering in scrolling WebViews.

Package identifiers and the Android signing identity are unchanged. Cloud lives
remain linked to the original account. Independent device lives remain local;
export them before uninstalling or clearing app data. A cloud/device save
conflict continues to require an explicit choice and retains a local archive.

The Android APK uses the existing production signature. The Windows x64
installer includes the WebView2 offline runtime and has no publisher certificate.
The universal macOS DMG is ad-hoc signed and not Apple notarized. SHA-256
checksums accompany the downloads. These are direct downloads, not app-store
listings.

Core play and the first cloud character are free. The optional US$3 Supporter
Pack includes cosmetics and an extra cloud character slot, before tax. It does
not grant stat boosts or improve odds. For adults 18+ and the local age of
adulthood, subject to the official Terms.

Android and macOS 0.2.2 downloads are also available at https://hilltahuang.itch.io/amiabot.
